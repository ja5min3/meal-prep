# 好好吃飯｜四盒減脂備餐

一次煮四份（兩人晚餐＋隔天兩個便當）的繁體中文備餐網頁：食譜、鑄鐵鍋時間表、四盒營養估算、冰箱找菜、採買清單。純靜態網頁，資料只存在使用者自己的瀏覽器。
